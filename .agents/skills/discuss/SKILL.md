# Discuss Mode

When this skill is activated (or the prompt starts with `[DISCUSS]` / `/discuss`):

1. **No Code Generation**: You MUST NOT generate code, create files, edit files, or program anything.
2. **Read-Only Research Allowed**: You MAY use read-only research tools (e.g., viewing files, searching the web, searching the codebase via grep or list_dir) to inform the discussion.
3. **Pure Discussion**: Discuss the problem, trade-offs, architecture, and design options directly with the user.
